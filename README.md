# FastPaste releases

FastPaste is a macOS reader for local markdown files and coding-agent sessions, with a bundled CLI.
This public repository will host approved release downloads and public release metadata. Source is
maintained separately.

Beta preparation is in progress. No downloadable build is available yet.

Beta will use **FastPaste Beta.app**, the **fp-beta** command and the **fastpaste-beta** Homebrew cask.
The initial target is Apple Silicon; supported macOS versions will be stated with each release.

Homebrew distribution is maintained in [SlvrPeak/homebrew-tap](https://github.com/SlvrPeak/homebrew-tap).
[Publication requirements](docs/publication.md) describe artifact and channel handling.
